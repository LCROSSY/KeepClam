# KeepClam 使用说明

启动 **KeepClam.app** 后，菜单栏出现「○ KeepClam」图标。所有操作通过菜单栏图标完成，关闭窗口（本应用无窗口）不影响运行。

## 安装与更新

推荐使用 [一行命令安装](../README.zh-CN.md#安装)：一条命令自动下载和校验安装包，显示版本与来源后由你按回车确认，然后安装并打开菜单栏应用。脚本下载的文件没有下载隔离标记，无需单独选择信任方式；应用仍未经过 Apple 公证。

已有安装包可用 `bash install.sh --local .` 离线安装；浏览器下载的 ZIP 带有下载隔离标记，此时会询问是否「安装并信任」（仅移除 KeepClam 的下载隔离标记）。更新时直接再运行安装命令：默认装回原来的位置；应用开着时会先自动退出，装完重新打开；合盖运行正在进行（保护进程在运行）时会取消替换，请先在菜单栏关闭合盖运行。通过 Homebrew 安装的版本，脚本会停止并提示运行 `brew upgrade --cask keepclam`。

首次打开的信任选择与下面的免密授权是两件事。安装脚本不会自动修改系统睡眠策略或安装 sudoers 白名单。

## 首次使用

1. **安装免密授权（推荐）**：菜单中点击「免密授权：未安装 — 点击安装」，输入一次管理员密码。之后开关合盖运行不再需要密码。
   - 白名单只放行两条命令：`/usr/bin/pmset -a disablesleep 0` 和 `1`。
   - 审计：`sudo cat /etc/sudoers.d/keepclam`；移除：`zsh scripts/uninstall-sudoers.sh`。
   - 不安装也可用：每次开关回退为管理员密码弹窗。
   - 合盖无人值守前必须安装：guard 与自动结束不能在后台弹出管理员密码框。
2. 点击「开启合盖运行」，图标变为「● KeepClam」。

## 菜单项

| 菜单项 | 说明 |
|---|---|
| 开启/关闭合盖运行 | 主开关；显示内核真实状态，外部开启会标注「外部开启的状态」 |
| 系统热状态 | 当前热等级（正常/略高/过高/严重过热） |
| 设置 ▸ | 自动结束、电池下限、日志频率、语言、查看运行日志（见下） |
| 免密授权 | 安装/查看 sudoers 白名单 |
| 退出并恢复睡眠 | 先恢复系统睡眠再退出；恢复失败会阻止退出 |

「设置」子菜单：

| 选项 | 说明 |
|---|---|
| 自动结束 | 会话时长：1 / 2 / 4 小时 / 无限（默认无限），或「自定义…」输入 1–1440 分钟；进行中在主菜单显示剩余时间 |
| 电池下限 | 10% / 20% / 30%（默认 20%），或「自定义…」输入 5%–95%；电池供电降到下限时恢复睡眠，合盖时立即休眠；接电源不触发 |
| 日志频率 | 采样聚合频率：5 秒 / 1 分钟 / 15 分钟，自动保存 |
| 语言 | 简体中文 / English / 跟随系统（默认跟随系统），切换即时生效，无需重启 |
| 查看运行日志 | 打开 `~/Library/Logs/KeepClam/运行日志.log` |

## 自动结束与保护

- **定时**：到时自动恢复睡眠并发通知，日志记 `auto_stop=timer`。
- **电池下限**：电池供电、电量降至下限即恢复睡眠，日志记 `auto_stop=battery_floor`；接通电源不受影响。
- **低电量模式**：电池供电 + 系统低电量模式时拒绝开启；会话中激活则自动恢复睡眠，日志记 `auto_stop=low_power_mode`。
- **过热保护**：独立守护进程每 5 秒检查热等级；过高/严重过热或连续 3 次读取失败时，先落盘告警，再恢复睡眠并请求立即休眠，同时发送系统通知。守护独立于应用存活——应用崩溃后仍会兜底恢复。
- 守护进程丢失时，应用会在一个检查周期内发现（日志记 `guard_missing`），发通知并自动尝试恢复睡眠；恢复失败会提示手动执行应急命令。

## 日志行为

- 会话期间按「日志频率」（默认 5 秒）采样盖状态、网络连通性、热状态；网络实测最多每分钟一次，`network_cached` 为最近结果。
- 连续相同采样按游程编码合并为一条摘要（起止时间、次数、最大间隔）；异常样本立即写入。正常摘要最长 15 分钟强制落盘。
- 单文件约 1 MiB 轮转，保留当前 + 3 份历史。

## 安全提醒

- 本应用为通用二进制（Apple Silicon 实测，Intel 未实测），临时签名、未公证。无终端窗口、无网页服务、无网络监听。
- 热保护是软件尽力保护，读取系统热等级而非摄氏温度。请保持通风，不要把运行中的合盖 Mac 放入包中。
- 大版本 macOS 升级后请重新验证。

## 应急恢复

```sh
sudo pmset -a disablesleep 0
pmset -g | grep SleepDisabled   # 不应出现 SleepDisabled 1
```
